# DevCatalitico-brecha-digital-las-colonias
Presentación interactiva en HTML sobre las actividades desarrolladas en el barrio Las Colonias (Soledad, Atlántico) para cerrar la brecha digital: difusión de tarifas sociales y jornadas de alfabetización digital. Incluye la reflexión sobre su aporte a los ODS 4, 9 y 10.
